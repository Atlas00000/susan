## 🎯 Key Features

### Three-Pillar AI System

**1. Chat (Discovery)**
```
User: "Help me find something"
AI: Conversational recommendations
Output: Text + Product links
```

**2. Search (Finding)**
```
User: "Show me bold scents under 60k"
AI: Query interpretation
Output: Filtered product grid
```

**3. Quiz (Matching)**
```
User: Takes 5-question quiz
AI: Personalized profile
Output: Custom recommendations with reasoning
```

## 🛠️ Technical Architecture

### Frontend
```
Framework: Next.js 14 (App Router)
Language: TypeScript
Styling: Tailwind CSS
Animations: Framer Motion
Package Manager: pnpm
```

### AI Stack
```
Provider: Groq
Model: Llama 3.3 70B Versatile
SDK: groq-sdk 0.33.0
Cost: $0 (Free tier)
Speed: 1-3 second responses
```

### Infrastructure
```
Container: Docker + Docker Compose
Development: Hot reload with Turbo
Analytics: Vercel Analytics
SEO: Structured data + Sitemap
```
